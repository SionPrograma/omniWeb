# OmniWeb QR Access System

This package contains the official QR access codes for the OmniWeb platform.

## QR Roles

| Role | Access Level | Purpose |
| :--- | :--- | :--- |
| **Creator** | Root / Full System | Direct ownership access with no restrictions. |
| **Admin** | System Management | Full platform management and governance oversight. |
| **Admin Candidate** | Verified Onboarding | Users on the track to becoming system administrators. |
| **Beta Tester** | Advanced User | Early access to new chips and features. |
| **Public** | Guest / View-only | Direct entry for the general public (safe mode). |

## How to use
1. Scan any of the included QR codes using your smartphone camera or any QR scanner app.
2. You will be automatically redirected to the OmniWeb shell.
3. Access is granted instantly via secure token mapping.

## File Formats
- **PNG**: Standard high-quality imagery for digital distribution.
- **SVG**: Vector graphics for printing and scaling without loss of detail.
- **Branding**: All QRs follow the Cyan-on-Nebula OmniWeb aesthetic for high contrast and technological feel.
