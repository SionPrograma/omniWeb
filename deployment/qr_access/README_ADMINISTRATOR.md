# Administrator Access (OMNI-ADMIN-COMMAND)

### Who should receive it?
- Fully vetted leaders who have completed Governance Training.
- Critical system moderators responsibly active for over a month.

### Role Assigned
**Administrator**
- Full governance voting rights.
- User moderation and system operation logs access.

### How it should be distributed?
- Manual Creator handover.
- Highly restricted and non-transferable.
