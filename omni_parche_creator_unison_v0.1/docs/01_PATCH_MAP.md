# Patch Map

## Capa 1 — Creator Command Gateway
Entrada unificada desde el chat del Creator Mode.

## Capa 2 — Intent + Capability Routing
Clasifica la misión y decide si:
- responder
- planear
- auditar
- editar
- comparar
- verificar
- consultar modelos open source

## Capa 3 — Open Source Capability Orchestration
Registro de modelos y herramientas open source bajo contrato unificado.

## Capa 4 — Workspace / Tool Bridge
Puente hacia editor, diffs, archivos, chips, dashboard y utilidades internas.

## Capa 5 — File Scope Governance
Control de cambios por archivo/rango, proposals, merge y rollback.

## Capa 6 — Response Critic + Auto Review
Revisión de claridad, coherencia, cumplimiento de misión y riesgo.

## Capa 7 — Evaluation Ledger
Registro de qué modelo/herramienta ayudó, cómo rindió y qué mejoró o empeoró.

## Capa 8 — Creator Approval Surface
Toda acción sensible vuelve al Creator con evidencia y confirmación.
