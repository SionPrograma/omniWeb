# OMNI_CREATOR_CHAT_DRIVEN_WORKFLOW — Requirements

**MISSION TITLE:** OMNI_CREATOR_CHAT_DRIVEN_WORKFLOW_MEMORY_SAVE  
**STATUS:** REGISTERED (HIGH PRIORITY)  
**TYPE:** Strategic / Interaction Principle

## 1. Interaction Core
The Creator must be able to guide the system via direct natural language (Chat/Voice).
- **Core Commands:** "analyze this", "audit this", "fix this", "inspect this chip", "repair this layer", "show me what you found", "prepare the patch".
- **Confirmation Rule:** "apply only after my confirmation".

## 2. Visible Work Principle (No Hidden Work)
Omni MUST NOT perform autonomous changes in the background without visibility.
- **Workflow Breaking:** Work must be broken into clear, manageable steps.
- **Visual Workspace:** Omni must show exactly what it is analyzing or doing inside the Creator workspace.
- **UI Comfort:** The visual experience should prioritize readability and comfort for the Creator.

## 3. Governance & Authority
- **Authority:** The Creator remains the final authority for all system mutations.
- **Manual Confirmation:** Omni must propose changes and request explicit human confirmation before sensitive/final execution.
- **Confirmation Flow:** Changes are only applied after approval.

## 4. Evidence & Verification
- **Truth at Runtime:** Visible evidence and mission results must be shown immediately after execution.
- **Traceability:** Every chat-driven action must be linkable to the audit/ledger system.

## Roadmap & Classification
- **Roadmap Position:** Strategic: Creator Surface Interaction (Post-Audit Surface V1).
- **Implementation Label:** `CREATOR_DRIVEN_VISIBLE_WORKFLOW`
- **Dependency:** Evidence Aggregation (Block 05), Audit Summary (Block 06).
